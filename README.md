# Camera--Scraps

A personal 3D CAD modeling project recreating my classic sony cybershot point-and-shoot digital camera. I built this for fun and practice to explore precision hard-surface CAD modeling and retro camera design details.

# Features & Design 

Front Housing:

- Multi-ring telescopic lens assembly with central shutter detail.
- Integrated flash diffuser bar and view-window/sensor cutouts.

Rear Controls & Interface:

- Large rear preview screen.
- Textured mode dial with custom mode icons (EASY, Program, ISO, Scene selection).
- Directional d-pad / navigation wheel with central selection button.
- Four dedicated soft-key action buttons surrounding the d-pad.
- Top Shutter button and power control.
